Module 07

Used to / would

Habitudes passées révolues : deux outils qui ne sont pas toujours interchangeables.

Le cours

FormeEmploiExemple
used to + base verbaleHabitude ou état passé qui n'existe plusShe used to live in Berlin.
would + base verbaleHabitude passée, action répétée uniquement (jamais un état)My grandfather would tell us stories.

Le piège principal

would ne peut jamais décrire un état (avoir, être, aimer, croire, habiter...) au passé habituel : seul used to le peut.

❌ This town would have a cinema.✅ This town used to have a cinema.
✅ Les deux fonctionnent pour une action répétée :Every summer, we would/used to spend two weeks there.

Attention au faux ami : be used to / get used to

be used to + -ing ne parle pas du tout d'habitude passée : ça signifie « être habitué à » (au présent). get used to + -ing signifie « s'habituer à » (processus en cours).

I'm used to working under pressure. (j'y suis habitué, maintenant) / It took her months to get used to the night shifts.

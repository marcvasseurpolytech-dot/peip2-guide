Module 04

Phrases exclamatives

How.../What a.../So.../Such a... : structures et pièges classiques.

Le cours

StructureEmploiExemple
How + adjectif/adverbe (+ sujet + verbe) Pas de nom après l'adjectif How beautiful this garden is!
What + a/an + adjectif + nom dénombrable singulier Article obligatoire au singulier What a fantastic idea!
What + adjectif + nom pluriel/indénombrable Pas d'article What lovely weather!
So + adjectif/adverbe Jamais suivi d'un nom directement This project is so complicated!
Such + a/an + adjectif + nom dénombrable singulier Article obligatoire au singulier It was such a difficult exam.
Such + adjectif + nom pluriel/indénombrable Pas d'article They are such generous people.

Le piège principal

So ne peut jamais précéder directement un nom : « so a good idea » est incorrect, il faut such a good idea. En revanche, so many / so much / so few / so little sont des exceptions figées qui, elles, précèdent bien un nom sans passer par « such ».

He made so many mistakes that he failed the test. (pas « such many »)
